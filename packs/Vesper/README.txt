# Vesper

Vesper is an API 1 pack combining volumetric fog, light shafts, storm clouds, dynamic weather, soft shadows, ambient occlusion, reflective water, and sepia tone mapping.

Requirements: Prisma 1.0 or later and Luanti 5.17. Each major effect can be adjusted through pack options.

The pack format and GLSL API are described in docs/shaderpacks.md, included in every Prisma release. Check the passes with prisma_check Vesper.
